# BID OWL P2-13 — 오프라인 합성 데모

이 데모는 **가상 공고와 합성 회사 프로필만** 보여주는 로컬 체험용 기능입니다. 실제 나라장터 공고나 고객 DB에 접근하지 않습니다. 인터넷·API 키·ReportLab·PDF 글꼴이 없어도 Python 3.11 이상만 있으면 실행할 수 있도록 설계했습니다. 상용 설치 패키지나 최종 자격 판정 서비스는 아닙니다.

## Windows 한 번 실행

압축을 푼 개발 브랜치의 최상위 폴더에서 `START_BID_OWL_DEMO.cmd`를 더블클릭합니다. 명령이 어려우면 `backend/START_DEMO.cmd`도 같은 기능입니다.

내부적으로 `backend/demo_local.py`가 OS의 임시 폴더에 새로운 `demo_only.sqlite3`를 만들고 합성 CSV 2건과 합성 회사 1건, 해당 평가 스냅샷을 저장한 뒤, `127.0.0.1`의 임의 빈 포트를 선택하여 읽기 전용 뷰어를 실행하고 기본 브라우저를 엽니다. 포트는 매번 다를 수 있으며 인터넷 공개 서버를 띄우지 않습니다.

콘솔에서 Ctrl+C로 종료하면 임시 데이터베이스도 삭제됩니다. 콘솔을 닫거나 PC가 비정상 종료된 경우 OS 임시 파일이 남을 수 있으므로 이를 고객 데이터 보존·영구 삭제 보장으로 표현해서는 안 됩니다.

브라우저 내 **'합성 데모 — 가상 입찰공고'** 배너와 공고의 `source_id=BIDOWL_SYNTHETIC_DEMO` / `source_ref=DEMO_ONLY`를 확인할 수 있습니다. 샘플 공고 하나는 2025년 만료 시나리오, 다른 하나는 2027년 미래 마감 시나리오입니다. 두 공고 모두 가상기관 데이터이며 실제 참가할 수 없습니다.

## 선택적 개발자 CLI

```powershell
cd backend
python demo_local.py
# 브라우저 없이 실행
python demo_local.py --no-browser
# 고정된 로컬 포트를 의도적으로 선택
python demo_local.py --port 8765
```

실행기는 별도 `--db` 인자를 제공하지 않습니다. 따라서 일반 사용자 DB를 데모 입력으로 선택할 수 없습니다. `create_demo_database`는 이미 존재하는 경로에 덮어쓰지 않고 실패합니다. 패키지의 예시 CSV에 `DEMO_ONLY`가 아닌 행이 있거나 회사 ID가 `SYNTHETIC-`으로 시작하지 않으면 DB를 만들기 전에 차단합니다. 화면은 기존 `viewer.make_server`를 사용하므로 DB 조회가 읽기 전용입니다.

## 테스트 및 제한

`backend/tests/test_demo_local.py`에는 신규 임시 DB와 합성 출처, 기존 파일 보호, 비합성 입력 거부 2종, 로컬 HTTP와 쓰기 거부, 종료 후 임시폴더 정리, 포트 유효성, 루트·백엔드 CMD와 UI 배너 검사 등 8개 테스트 메서드가 있습니다. 이것은 **테스트 구현 수**이며 현재 전체 GitHub 원본에 대한 실제 Python/Windows 실행 PASS가 아닙니다.

보안 및 실행 제한: 로컬 브라우저 UI만 표시하며 기존 BASIC 기능처럼 공고 CSV 가져오기, 회사 정보 변경, PDF 출력은 별도 명시적 로컬 CLI가 필요합니다. 실사용 업무 흐름, 설치 패키징, Windows 보안 제품, Excel/PDF 네이티브 출력과 실제 1만 공고 성능은 검증 전입니다. 고객 파일·키·거래내역을 데모에 입력하거나 GitHub에 업로드하지 마세요.
